---

## 4. Documented Limitations

1. Synthetic telemetry — no real-infrastructure validation
2. Simulated recovery — no real cloud API integration
3. Sudden failure detection is inherently weaker (F1 0.529 vs 0.864 for gradual)
4. Root-cause inference is heuristic, not causal
5. Post-healing verification uses synthetic normal telemetry
6. Prototype model training at server initialisation
7. Logistic Regression is interpretable but not the highest-performing model
8. Early-warning label definition includes current failure timestep (not purely future)
9. No real-world validation on external cloud trace datasets
